# Security Policy

## Supported Versions

Only the latest release running on the `main` branch receives active security updates.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| < 0.1   | No        |

## Reporting a Vulnerability

If you identify a security vulnerability in Relatronica, please report it responsibly:

1. Do not report security vulnerabilities via public GitHub issues, discussions, or social channels.
2. Email your findings directly to the maintainers at: `security@relatronica.com` (or submit a private security advisory through GitHub).
3. Include the following details in your report:
   - Type of vulnerability (e.g., authentication bypass, data exposure, XSS).
   - Detailed step-by-step reproduction instructions.
   - Affected URLs, routes, or files.
   - Proof of concept code or payloads, if applicable.
   - Suggested mitigations, if known.

## Vulnerability Handling Process

- Maintainers will acknowledge receipt of your report within 48 business hours.
- A private review and severity assessment will be conducted.
- A fix will be developed in a private branch and validated.
- Once deployed, appropriate credit will be acknowledged in the release notes unless you request anonymity.
